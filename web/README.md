# Shock Lab web

Next.js (App Router) + TypeScript + Tailwind v4 + D3 + Framer Motion dashboard.

```bash
npm install
NEXT_PUBLIC_API_URL=http://localhost:8000 npm run dev
```

All data comes from the FastAPI service (`/meta`, `/stress`, `/optimize`, `/events`, `/backtest`, `/comparison`).
See the root README for the full project.
